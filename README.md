# Interactive Rating Component

![Design preview for the Interactive rating component](./preview.jpg)

A responsive interactive rating component built with HTML, CSS, and JavaScript.

## Features

- Select rating from 1-5 with visual feedback
- Submit functionality with validation
- Responsive design for mobile and desktop
- Smooth transitions and hover effects
- Accessibility support

## Technologies Used

- HTML5 (semantic structure)
- CSS3 (flexbox, transitions, responsive design)
- Vanilla JavaScript (DOM manipulation, event handling)

## Getting Started

Open `index.html` in your browser to view the component.
